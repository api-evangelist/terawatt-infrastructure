## What Terawatt is, for an agent

Terawatt is an infrastructure owner-operator, not an API provider. Its assets are real
estate, grid interconnection and high-power charging hardware, run with proprietary
Charge Management Software and an operations and maintenance program. Notable sites
include the I-10 electrified corridor and locations serving the Ports of Los Angeles and
Long Beach.

## Developer / API surface

**There is none that is publicly reachable.** As of 2026-08-30:

- No developer portal, API reference, or SDK. `/developers`, `/docs`, `/api` all 404.
- No machine-readable contract. No OpenAPI, AsyncAPI, GraphQL SDL, Postman collection
  or JSON Schema at any discoverable location.
- No `.well-known` documents at all — security.txt, api-catalog, OAuth/OIDC metadata,
  agent card and ai-plugin manifest all 404.
- No MCP server and no A2A agent card.
- No API host in DNS. `api.`, `app.`, `developer.`, `docs.`, `portal.`, `ocpi.` and six
  other candidate subdomains of `terawattinfrastructure.com` are all NXDOMAIN.
- No public GitHub organization; no packages on npm, PyPI or any other registry.

**One integration surface exists but is customer-only.** Terawatt states in its own
engineering blog that it has "implemented Open Charge Point Interface (OCPI) with custom
extensions, which gives our customers visibility into our charging facility." OCPI is the
e-mobility roaming standard. No OCPI version-discovery endpoint answers anonymously
(`/ocpi/versions` → 404), no OCPI version or module list is published, and the custom
extensions are undocumented. A fleet operator gets this surface through a commercial
agreement, not through a signup.

Terawatt also runs a customer reservations portal (pre-booking charging sessions up to a
year ahead, with dynamic stall reassignment) and delivers charge-session data with per-kWh
billing through customer dashboards. Neither is exposed as a public API.

## Pricing

No published pricing. No plan tiers, no rate card. The commercial motion is a contact form
leading to a negotiated charging-as-a-service or site agreement. Billing is per kWh; the
rate is not public.
